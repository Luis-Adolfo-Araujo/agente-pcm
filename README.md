# Assets de marca

`senai.svg` — logotipo SENAI extraído do spritemap institucional publicado em
portaldaindustria.com.br (símbolo `senai-logo`, 136×36). O arquivo de origem é a versão
negativa (toda branca); aqui ele está na **aplicação monocromática em azul #164194**, que é
uma das três autorizadas pelo Manual de Marcas do Sistema Indústria (2024): preto, branco ou
azul.

Isto é um substituto operacional. A versão de duas cores, com o pingo do "i" em laranja
#E84910, deve vir da área de comunicação de quem opera o sistema — basta sobrescrever este
arquivo mantendo o nome. A altura de exibição é 36 px, a redução mínima do manual para
desktop, e a área de proteção 2x é aplicada pela classe `.brand-signature`.
